Uproot は、純粋な Python で ROOT ファイルの読み書きを行うための Python ライブラリです。ROOT は高エネルギー物理学におけるデータの標準的なファイル形式であり、現在 2 エクサバイトを超えるデータが ROOT ファイルに保存されています。従来、ROOT はインストールが難しいことで知られていたため、Uproot は研究者が Python でデータを読み書きできる軽量な代替手段として生まれました。Uproot は、データ解析のための幅広いツールを提供する Scikit-HEP パッケージ群の一部です。
